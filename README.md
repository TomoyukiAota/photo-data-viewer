# Photo Data Viewer

This application displays the EXIF data of your photo.

[Click here to use this application.](https://photo-data-viewer.vercel.app/)

## Supported browsers

The updated application supports these browser versions and later:

| Browser                       | Minimum version |
| ----------------------------- | --------------- |
| Chrome                        | 117             |
| Microsoft Edge                | 121             |
| Firefox                       | 121             |
| Safari (macOS and iOS/iPadOS) | 17              |

See [upgrade results](./docs/dependency-upgrade-evidence/RESULTS.md) for validation
coverage and known limitations.
